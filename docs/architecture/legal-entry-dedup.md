# 协议入口单一归属

对应需求：[协议入口去重](../feature/legal-entry-dedup.md)。原型：[Web 用户端](../demo-static/web/user/legal-entry-dedup.html)。

全局页脚负责 BGSSAI 协议 URL、标签和语言；登录同意组件只渲染提示及现有受控勾选框。避免通过 CSS 隐藏重复内容或在 DOM 中事后去重。设置页不再重复生成 terms/privacy 列表，可保留独立的法律信息中心链接。公共布局挂载点维持唯一，不按业务页追加页脚。

不修改认证请求、同意版本、存储键、按钮禁用条件、协议正文、备案号。浮动入口在窄屏应为协议链接预留空间，必要时改为独立布局行。无全局页脚的客户端按当前页面保留唯一同意链接，设置列表与页脚不得同时展示同一组。构建产物由各仓既有构建/部署流程生成。

验证按当前源码分别执行构建及浏览器检查：登录、注册/验证码模式、公开页面和设置（可访问时）；窄屏 320px 与桌面 1440px；检查可见协议链接数量、目标地址、备案显示、横向溢出及复选框。自动检查与未运行的真机/线上验证分列，不以源文件存在认定上线完成。
