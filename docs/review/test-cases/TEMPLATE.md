# 功能测试用例模板（TEMPLATE）

> 可复用于其它 BGSSAI 产品。按 `docs/feature/<feature>.md` 的「验收标准」1:1 展开；OUT-OF-SCOPE 标 N/A。

## 元信息

| 字段 | 填写说明 |
| --- | --- |
| 产品 / 仓库 | 如 bgssai-wiki / liuliuzo/bgssai-wiki |
| 功能文档 | `docs/feature/<slug>.md` |
| 功能 slug | 小写连字符，与文件名一致 |
| 分支 / 版本 | 如 develop |
| 环境 | User / Admin 域名（勿写入密钥） |
| 编写人 / 日期 | |

## 用例表（复制下方表头）

| 用例ID | 关联需求/AC | 优先级 | 端(user/admin) | 前置条件 | 测试步骤 | 期望结果 | 测试数据 | 环境 | 结果(待测) | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| TC-XXX-FEATURE-01 | AC-1 | P0 | user | … | 1. …<br>2. … | … | … | https://dev.user.bgssai-wiki.com | 待测 | |

## 列说明

| 列 | 说明 |
| --- | --- |
| 用例ID | `TC-<产品缩写>-<功能缩写>-<序号>`，如 `TC-WIKI-LOGIN-01` |
| 关联需求/AC | 对应验收标准编号或原文摘要 |
| 优先级 | P0 阻塞 / P1 核心 / P2 重要 / P3 次要 |
| 端 | `user` / `admin` / `both` / `api` / `cli` |
| 前置条件 | 账号角色、数据、配置（不含密钥明文） |
| 测试步骤 | 编号步骤，含具体 URL / 路由 |
| 期望结果 | 可判定的 UI / API / 状态 |
| 测试数据 | 账号占位、样例文件名等（无口令/Token） |
| 环境 | 用户端 / 管理端域名 |
| 结果 | 待测 / 通过 / 失败 / 阻塞 / N/A |
| 备注 | 边界、已知限制、PENDING E2E 等 |

## 编写约定

1. 每条编号验收标准至少 1 条正向用例；AC 暗示的负向 / 边界另补。
2. OUT-OF-SCOPE 功能：索引标 N/A，可不建用例表或建空壳说明「不可测」。
3. 禁止写入口令、JWT、PAT、AK/SK、短信密钥等密钥。
4. 真机 / 真实模型未验收项在备注标 **PENDING**，不得记 PASS。
