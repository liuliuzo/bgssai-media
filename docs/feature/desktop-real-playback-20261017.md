# PC 本地与平台视频真实播放

对应 REQ-MEDIA-PC-PRODUCT-006/007/008。PC 同时提供本地主流格式播放器和平台视频播放；Web、Android、iOS 使用独立客户端和本仓平台 API。

1. 有 VLC 时继续由 VLC 实际输出音画；没有 VLC 时使用随桌面程序打包的 FFprobe/FFmpeg，将实际媒体转为 H.264/AAC MP4，交由桌面内的视频窗口播放。准备完成前展示处理中；解码失败显示具体错误，不报告播放成功。
2. 本地文件及平台返回的 HTTP/HTTPS 视频地址共用播放控制。临时转码只在本机进行，原始文件不变；切换文件、停止及退出回收子进程与临时文件。
3. 音轨、字幕、时长来自实际探测。文本字幕可转 WebVTT；图形字幕明确不支持内置路径，不生成虚构轨道。播放、暂停、定位、音量、倍速、全屏作用于实际视频；状态以播放器事件为准。
4. PC 提供已发布创作者作品列表，使用现有社区与播放接口；不可播、下架、未登录和网络失败显示真实结果。

内置路径首次播放等待转码完成，长视频准备耗时取决于本机；VLC 路径适合大文件直接播放。格式目标由现有矩阵管理，本次样本通过不等于所有平台/编码已验收。不改变平台 API、数据库或计费规则，不部署。
