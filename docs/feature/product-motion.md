# 用户端动态视觉（2026-09-25）

入口页采用与官网一致的细线轨道、流动连接线和浮动卡片；中心图形对应本产品主题。
落点：`bgssai-media-user/frontend/src/pages/LoginPage.tsx`。

这是非功能性的视觉增强，不改变账号、表单、接口、字段、页面跳转或数据库。
原型与接口设计层不涉及契约变更；正式 React 页面即视觉验收对象。

## 动效与验收

- 图形由 HTML / SVG / CSS 构成，没有第三方动画依赖、网络请求或计时器。
- 入场与连线动画最多播放 4.8 秒，之后保留静态图；不会无限循环干扰阅读。
- 系统开启减少动态效果时从首帧展示静态图，不隐藏文字或操作。
- 装饰图 aria-hidden，不进入键盘焦点或屏幕阅读顺序，也不拦截点击。
- 容器预留高度，窄屏缩小；不在对话消息、编辑器或业务表格上叠加动画。
- 验证生产构建，检查桌面、375px 窄屏、减少动态效果和动画结束后的状态。
